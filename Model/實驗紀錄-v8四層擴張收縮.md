# v8：每個殘差區塊改為四層，兩次擴張再兩次收縮

> 此檔為舊四層 v8。使用者後續新 v8 是兩層 24→96→24，見實驗紀錄-v8通道96.md。以目前程式重現本檔舊版訓練，需加 `--v8-variant legacy_four_layer`；舊 checkpoint 自帶 residual_layers=4，仍會載入原架構。

## 目的與變更

使用者要求第一層擴大兩倍、第二層再擴大兩倍、第三層縮小兩倍、第四層再縮小兩倍。沿用前次通道擴張的定義，實作為 **24→48→96→48→24**；指的是通道數，不是每層卷積的權重數恰好乘除二。每層皆為 3×3、stride 1、padding 1，前三層後接 ReLU，第四層後加回區塊輸入。

```text
x（24） ─────────────────────────────────────────────┐
 └→ Conv 24→48 → ReLU → Conv 48→96 → ReLU              │
       → Conv 96→48 → ReLU → Conv 48→24 ────────────→ 相加
```

保持五個殘差區塊，每個區塊由兩層改為四層；影像主幹含輸入與輸出卷積共 **22 層卷積**。總參數 **530,268**，v7 為 114,828。單一區塊四層參數量（含 bias）依序為 10,416／41,568／41,520／10,392，共 103,896。

版本為 `architecture=v8`，設定保存 `residual_blocks=5`、`residual_expansion=2`、`residual_layers=4`。舊 v7 的 24→48→24 區塊及 checkpoint 載入方式保留，新模型從頭訓練。

輸入仍是當前＋前一幀，兩幀各有 encoded 與同筆 JPEG XS 實際 decoded 的 160×4 RAW；輸出為當前 640×16 RAW8 RGGB。byte encoder、phase 對齊、固定時間權重、當前 decoded 放大基準及 RAW L1 loss 沿用。最終殘差預測層零初始化，初始輸出等於 phase-aware bilinear 基準。

## 資料與訓練預算

資料：`training-data-preparation/拆好的訓練資料/big-buck-bunny-30s-q6-shared-v3-raw8.sqlite`，Q=6、schema 3、固定 shared header。實際解碼快取為 `runs/decoded-q6.npz`，以資料指紋核對，沒有從高解析度標籤降採樣產生 decoded。

- 訓練來源 frame 0…719，有效當前幀 1…719，共 21,570 窗口。
- 驗證來源 frame 720…899，有效當前幀 721…899，共 5,370 窗口；歷史不跨切分。
- 新舊模型均從頭完整訓練 5 輪，Adam、lr=0.001、batch size=8、seed=42、FP32、時間衰減=0.2、殘差幅度=0.5，沒有截短步數。
- 相同輪數與主要超參數不等同相同計算量；架構不同，相同 seed 也不代表各層具有相同初值。
- 僅單一 seed、同一部影片保留區段，未建立新影片泛化結論。先前 4,950 窗口的十六幀比較不與本次混比。

## 執行狀態

正式五輪已完成。16 項模型／紀錄測試通過，包含四層通道順序、shortcut、零初始化基準、所有區塊卷積梯度、前一幀 decoded 梯度與 checkpoint 重建。

訓練原始 metrics.jsonl 顯示各輪驗證 MAE／PSNR 為 24.905／17.679、22.702／18.150、21.572／18.476、20.941／18.562、22.392／18.072。最佳為第 4 輪。相同 5,370 窗口與五輪預算下，落後 v7 的 19.865／18.986；增加容量在本次實驗未改善。使用者已要求回到 v7。此處依原始數值補正先前「進行中」的過期描述，原始實驗紀錄不改寫。

權重保存於 `runs/hybrid-v8-history2-expand4layer/best.pt` 與 last.pt；逐輪曲線見該目錄 metrics.jsonl。尚未完成獨立對照影片及視覺驗收，不作新影片或即時性結論。

## 重現

```powershell
$datasetPath = 'training-data-preparation/拆好的訓練資料/big-buck-bunny-30s-q6-shared-v3-raw8.sqlite'
.\Model\.venv\Scripts\python.exe Model/train.py --db $datasetPath --architecture v8 --v8-variant legacy_four_layer --decoded-cache Model/runs/decoded-q6.npz --history 2 --device cuda --epochs 5 --out Model/runs/hybrid-v8-history2-expand4layer-repeat
.\Model\.venv\Scripts\python.exe Model/evaluate.py --db $datasetPath --decoded-cache Model/runs/decoded-q6.npz --checkpoint Model/runs/hybrid-v7-history2-expand2/best.pt Model/runs/hybrid-v8-history2-expand4layer-repeat/best.pt --start-frame 720 --video --out Model/runs/eval-hybrid-v8-expand4layer-repeat
```

輸出目錄須使用未存在的名稱，保留所有既有產物；全部實驗見 [實驗總表](./實驗總表.md)。本階段優先品質，未做效能量測。

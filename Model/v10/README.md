# v10：以可靠底圖為條件，生成缺少的細節

**本次主線：實際 decoded＋由同份 decoded 計算的 bilinear 放大圖，搭配條件式殘差擴散。** bilinear 作為低成本底圖，v10負責修復與生成缺少的紋理。目標是在保住物體、輪廓、位置與顏色的前提下，生成合理的草地、毛髮、樹葉等紋理；不能以放大尺寸、銳化、增加高頻能量或降低 MAE 冒充生成成功。

輸入範圍沿用本幀本條與緊接前幀本條：decoded `[B,2,1,4,160]`、bilinear RAW `[B,2,1,16,640]`，另有phase `[B,2]`。兩路都在訓練／推理時提供，bilinear由各幀decoded依自身phase計算；生成時的噪聲與時間步是模型內部狀態。主流程不需要v9權重或v9推論，v9僅保留為品質對照。

目前是**第一版實作完成、55項測試與短流程通過，正式Q=5二十輪訓練執行中**。已有流程檢查與訓練中的checkpoint，但沒有已通過生成品質的權重；初期輸出仍嚴重失真。進度、指令與限制見 [實作／訓練紀錄](../實驗紀錄-v10雙路殘差擴散Q5.md)。

入口為 `Model/train_v10.py`、`Model/evaluate_v10.py`、`Model/predict_v10.py`；主體與sampler在本目錄。正式訓練每輪21,570條，以固定256條生成選模，完整5,370條驗證與影片驗收另外執行，不能把短跑或選模子集當作完整品質結果。

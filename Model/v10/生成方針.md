# v10 生成方針：decoded＋bilinear底圖的條件式殘差擴散

> 更新：第一版已依此規格實作，55項測試與短流程通過，正式Q=5二十輪訓練執行中；尚未通過品質驗收。下文保留研究方針與規劃預算，不能當作已完成的結果；實測及實作差異見 [實作／訓練紀錄](../實驗紀錄-v10雙路殘差擴散Q5.md)。

## 1. 本次目標與決策

保住輸入已提供的物體、輪廓、位置與顏色，再利用學到的影像先驗補出合理紋理。草地、毛髮或樹葉可以與原圖的每一根不同，但要與材質、邊界、運動一致，不能只是噪點、銳化白邊、假物體或逐幀跳動的內容。

**依使用者最新決定，主線輸入改為「實際decoded＋bilinear放大圖」，訓練條件式殘差擴散模型。** bilinear提供低成本的畫面底圖，v10同時學修復底圖誤差與生成合理細節；主流程移除v9前置模型，只把v9當作品質對照。不增加鄰條、不改成16幀、不重設JPEG XS流程。先證明能生成合理細節，再解決時間穩定與少步推理；最後才研究部署速度。

bilinear是decoded的確定性轉換，不增加新的觀測資訊，也不是零運算成本。兩路輸入的作用是讓模型同時取得原始低解析樣本與便宜的高解析空間基準；不能僅把同一張bilinear複製兩次當成雙分支已完成。

輸出尺寸變大、頻譜高頻變強、MAE下降、模型參數變多，都不能單獨算「長出細節」。生成的是與輸入相容的可能內容，不宣稱找回已不可辨識的真實資訊。

## 4. 核心演算法

令 `b_t = bilinear(decoded_t, phase_t)`、`b_prev = bilinear(decoded_prev, phase_prev)`，主輸出底圖 `b = b_t`。`y`為訓練標籤，`P`為pixel_unshuffle(2)，將RAW拆成四個CFA平面。

```text
實際decoded雙幀 ── 低解析特徵分支 ─────────────────┐
      │                                             │
      └─ 各自依phase做bilinear ── 高解析底圖分支 ────┤
                                                    ▼
高斯噪聲 ── 多步條件式殘差去噪 ── 生成殘差 ── 加回本幀bilinear ──► RAW輸出
```

訓練時：

```text
r0 = (P(y) − P(b)) / s
rt = sqrt(alpha_bar[t]) * r0 + sqrt(1 − alpha_bar[t]) * epsilon
epsilon ~ Normal(0, I)
epsilon_hat = D_theta(rt, t, c)
L_diff = mean((epsilon_hat − epsilon)^2)
```

`s`為只用train殘差擬合的逐CFA通道標準差，下限0.01，保存統計方法與數值。殘差允許正負，不先量化、不截成RAW8，不能用validation／test擬合尺度。

條件`c`包含兩幀decoded的低解析特徵、兩幀bilinear的四平面，以及兩幀phase embedding。decoded需有直接的低解析特徵分支，不以先放大後的圖取代原始decoded。推理條件不能包含y、乾淨r0、v9輸出或任何由標籤產生的特徵。

推理從純高斯殘差噪聲開始，按排程逐步去噪，得到`r_hat`：

```text
out = pixel_shuffle(P(b) + gamma * s * r_hat, 2)
out = clamp(out, 0, 1)
```

gamma=0必須逐值等於本幀相位對齊bilinear底圖。gamma控制生成強度，並不保證品質；以底圖做殘差相加也不會自動保護輪廓，仍須內容護欄與驗收。訓練殘差的定義已改為「原圖減bilinear」，不能混用先前規劃的「原圖減v9」殘差或尺度統計。

主線不採「bilinear加一次雜訊，再用一次L1預測原圖」。這個方法作為對照，因為模型可能忽略噪聲而回到平滑的點估計。擴散雖也用MSE，但學的是多個噪聲層級的去噪／條件分布，再經多步採樣生成，與直接最小化最終圖片的逐像素MSE不同。

## 5. 第一版網路與固定預算

先使用像素域RAW四平面殘差，避免一開始引入RGB VAE、文字提示或大型文字生成模型。

- 去噪張量為`[B,4,8,320]`，不直接混合Bayer馬賽克相鄰顏色做濾波。
- decoded分支：各幀先拆成`[B,4,2,80]`，共用兩層3×3 Conv 4→16→16及SiLU，在低解析網格提取特徵，再依各幀phase的座標網格對齊到8×320；對齊沿用既有取樣座標規則。兩幀各16個特徵通道，不固定時間平均。
- bilinear分支：各幀放大RAW拆成`[B,4,8,320]`，兩幀串接為8通道，保留其高解析空間基準。
- 去噪器融合通道：帶噪殘差4＋decoded兩幀特徵32＋bilinear兩幀8＋兩幀各8維phase embedding16，合計60。decoded分支保留原始低解析特徵提取，不能只複製bilinear通道。
- 初始骨架：Conv 60→48，4個時間條件殘差區塊，每區塊兩層3×3、GroupNorm(8)、SiLU；時間embedding用128維正弦編碼＋MLP，提供通道縮放／偏移；最後Conv 48→4預測epsilon。
- 四區塊水平dilation先固定1、2、4、8，垂直dilation=1；padding採replicate並明確測試。沒有垂直下採樣、attention或VAE。
- 正向噪聲排程初始選cosine、1,000時間步；推理先用DDIM 32步、eta=0，16步為固定對照。eta=0不代表結果與初始噪聲無關。
- AdamW，lr=1e-4、weight_decay=1e-4、gradient clip=1.0，seed=42，優先FP32，從頭完整20輪作首輪配置的預算上限。
- 有效batch=16，顯存不足以microbatch=4、累積4次達成，保存實際optimizer steps。每輪完整21,570條；短跑只標記流程檢查。

bilinear底圖可即時計算或預先快取；快取必須綁定DB、decoded、phase、插值設定與程式指紋，train與validation分離，抽樣重算核對。主線不建立或載入v9底圖快取；decoded分支參數隨v10一起訓練。條件中不得混入標籤或乾淨殘差。

每輪保存loss與去噪驗證診斷。低成本生成選模使用固定256個validation窗口，依phase分層、保存鍵值；epoch 5／10／20輸出固定seed與固定步數的預覽。最終完整5,370條評估須明載這是已參與選模的同影片驗證集。

在看結果前固定gamma候選`{0,0.25,0.5,0.75,1}`，展示品質／失真的取捨。只能在上述選模集合選擇，不逐條看原圖挑gamma，也不對每張圖挑最好看的seed。上述架構和預算都是初始假設，沒有v10結果支持它們最優。

## 6. 損失如何服務生成

第一個擴散實驗以L_diff為主，先確認能產生結構化殘差，不同時疊GAN、VGG、小波與大量加權項。

第二個實驗加弱低頻內容護欄：由epsilon_hat解出預測乾淨殘差，組成out_hat，再比較`LP(out_hat)`與`LP(y)`。LP在各CFA平面分別用固定sigma=1的5×5 Gaussian、replicate邊界。起始權重0.1，與權重0的結果分開比較；初始只在t<800啟用，避免近純噪聲時x0反解不穩，實際規則保存於config。

不以很大的逐像素L1把全部高頻殘差壓回零。decoded含有損編碼誤差，不強制輸出在取樣位置逐值等於decoded；應比較底圖／模型在那些位置對原始標籤的誤差。如加入decoded一致性，只能用帶容忍度的軟約束，且獨立消融。

首輪不把VGG感知loss硬套在僅16列的條帶，也不靠拉伸條帶成方圖取得好分數。完整畫面LPIPS只作輔助評估。後續若研究完整畫面感知loss／判別器，須另列實驗，推理輸入仍不得偷讀鄰條。

## 7. 實驗順序與必要對照

| 階段 | 實驗 | 要回答的問題 |
| --- | --- | --- |
| S0 | decoded／bilinear配對、phase／切分／底圖核對、gamma=0 | 新流程是否精確還原已知bilinear基線？ |
| S1 | 同一去噪骨架，噪聲槽填0／時間固定，用Charbonnier直接訓練殘差；另跑「單次加噪＋L1」 | 改善是否只是多加一個修圖網路？噪聲是否被忽略？ |
| S2 | 條件式殘差擴散，先L_diff，再對照低頻護欄 | 多步生成能否長出合理紋理並保留內容？ |
| S3 | 逐幀獨立seed與固定畫面座標噪聲對照，必要時加入時序微調 | 是否閃爍、黏屏、鬼影或跨條斷裂？ |
| S4 | 32→16步；品質成立後才研究4／1步蒸餾；匹配Q的新影片測試 | 少步數能否保住生成品質及泛化？ |

S1與S2每個訓練配置使用相同資料、有效batch、20輪與seed，列出實際計算量差異。不能讓生成模型多訓練很多次，卻把同預算對照當作已完成。

輸入消融獨立列為「decoded-only」「bilinear-only」「decoded＋bilinear」：保持雙幀範圍、去噪骨架、預算與seed相同，以遮罩關閉對應條件分支；三者的輸出殘差仍加回同一份本幀bilinear，明確區分模型條件和輸出skip底圖。v9只保留直接重建的品質參考，不作主線必要前置；若未來比較v9底圖＋生成器，必須另記其訓練／推理成本與條件，不能混入主線。

若S2只有噪點、忽略噪聲或生成無關紋理，先檢查條件使用、殘差尺度、排程、資料多樣性與train／inference一致性，不靠加寬或銳化無限重試。排查後仍無收益，下一個可比較方案為「同底圖＋感知／條件判別器」殘差生成器；它是獨立路線，不能混入擴散成果。

## 8. 影片一致性與條界

固定seed不保證穩定：逐幀獨立噪聲可能閃爍；固定畫面座標噪聲可能讓紋理黏在螢幕。兩種都必須看運動片段，不以其中一種看似穩定就宣布通過。

S3如加入warp／時序loss，位移與信心只根據可用的當前／前幀decoded估計，CFA分平面處理，phase與物體運動分開。流出條帶、遮擋、低信心位置不強制一致；4列輸入能否可靠估運動是待驗問題，不能預設光流一定有效。

比較生成的相鄰幀差異與標籤的相鄰幀差異；如使用warp，對兩者使用同一warp與遮罩。不能直接逼兩幀相同而抹掉真實運動。先不使用前幀生成圖或遞迴噪聲狀態，避免改變兩幀契約。

若時序訓練用相鄰目標對，每次模型呼叫仍只看自己的當前／前幀，但兩次呼叫聯集會覆蓋3個來源影格；對數、有效窗口、切分與預算須重新列，不能以21,570條冒充21,570對。

重建完整畫面後檢查每16列邊界附近相對標籤的誤差，並和條內比較；不能只看單條PNG。訓練／推理不因接縫而默默加入鄰條，若條界一直無法改善就如實記失敗。

## 9. 成功必須超過「銳化與加噪」

固定對照至少包括：目標、bilinear底圖、同骨架非生成修復、bilinear＋固定銳化、bilinear＋匹配高頻能量的高通噪聲、擴散結果、官方FSR及獨立的v9雙幀品質參考。銳化與噪聲控制參數只用train調定，不拿val原圖逐條對答案。

所有方法使用同筆實際decoded、同裁切、同顯色與同RGB參考。完整640×480、固定紋理ROI、連續影片都要展示；ROI在看生成結果前選定並保存，不只挑成功例。

- **內容**：物體數量、輪廓、位置與主要顏色保留，可靠取樣內容不被抹掉；報告低頻誤差、色偏、最差條塊。
- **生成**：紋理與材質／邊緣相符，視覺優於底圖、銳化與匹配噪聲；僅頻譜能量增加不算。
- **影片**：不同phase與運動下，沒有新增明顯閃爍、鬼影、黏屏或條界跳動。
- **隨機性**：seed=0固定作主報告，seed=1／2展示同條件的候選差異。差異應集中在欠定細節，不能連物體／顏色都改掉；多樣性本身不是品質。
- **數值**：完整5,370條RAW MAE／PSNR、RGB指標、逐條勝率、最差10% MAE、phase分組、條界、低／高頻誤差；完整畫面LPIPS／頻譜作輔助，不以小樣本FID或單一感知分數決勝。

首次候選篩選的基準改為實際使用的bilinear底圖：RAW MAE不超過bilinear的1.05倍、PSNR下降不超過0.5dB、最差10% MAE不超過bilinear的1.10倍。另行列出對v9的差距，不把底圖成本降低當作品質進步。超出護欄者列為內容失真明顯的生成候選，不直接替換。這是初始研究護欄，不是品質通過線；原FSR門檻仍保留，也不是已經過使用者驗收的門檻，不能取代原 [驗收標準](../驗收標準.md)。

效能需拆報JPEG XS解碼、bilinear、decoded條件特徵提取、每步去噪／總採樣與端到端時間；固定decoded／bilinear條件特徵每條只計算一次，在去噪步間重用。主線沒有v9前置成本，但生成器若需要更多修復能力或步數，總成本仍可能增加，必須實測。

若觀感較佳而原FSR數值門檻沒過，標示「視覺候選／數值未通過」，給出左右隨機順序的盲比影片與明確取捨，不能自行改成正式通過。人工評分保存評分者、題目、樣本、平手與失敗例；同片相鄰幀不冒充獨立樣本做顯著性宣稱。

## 10. 下一輪實作與紀錄要求

1. 建立decoded＋bilinear雙路資料介面，核對兩路來自相同碼流／幀／本條，先驗證來源、phase、切分與gamma=0，不載入v9模型。
2. 實作殘差尺度、噪聲排程、時間條件去噪器與DDIM，跑有持久紀錄的流程檢查。
3. 跑S1／S2正式預算，輸出固定gamma／seed對照、完整影片、獨立生成影片與失敗條塊。
4. 生成細節確認有效後才進S3，再做S4與Q=4。

最低正確性檢查：16相／CFA排列、兩幀索引、decoded與bilinear配對／重算一致、兩個條件分支都影響輸出並能取得梯度、無跨切分、推理不讀標籤或v9、gamma=0逐值等於本幀bilinear、加噪與反解數值一致、seed重現、batch分拆不改結果、殘差正負／尺度、模型與sampler checkpoint重建。

相位跨子像素邊界含空間進位，不能沿用舊草案「只roll16通道即可精確對齊」的未驗證主張。本次使用已驗證的座標取樣，不重新發明相位上採樣。

新入口維持run_logged、逐輪update_active_record；保存noise schedule、sampler／步數／eta、seed policy、gamma、bilinear實作／設定、資料雜湊與程式版本。v9權重只在評估參考中記指紋。子目錄新程式須納入來源快照，不能漏掉生成器或sampler。小型紀錄在experiments/records，逐條結果在experiments/details，大權重／影片在新runs目錄，不覆寫或刪掉負面結果。

## 11. 已查證文獻與適用邊界

- [SR3](https://arxiv.org/abs/2104.07636)：條件式去噪訓練與多步生成超解析，支持程序方向，沒有處理本專案4列RAW條帶。
- [ResDiff](https://arxiv.org/abs/2303.08714)：CNN初始重建＋真值與CNN輸出間殘差的擴散，可借用「底圖／殘差分工」概念；本計畫底圖已依使用者決定改為bilinear，並非其CNN底圖或完整重現，CFA條件與生成器仍須自行驗證。
- [ResShift](https://arxiv.org/abs/2307.12348)：用殘差位移設計減少採樣步數，可供後續效率研究；其步數或速度不能直接套到本專案。
- [TecoGAN](https://arxiv.org/abs/1811.09393)：時序學習目標與生成細節的一致性，支持影片驗收的重要性，不保證本次兩幀條帶設定有效。

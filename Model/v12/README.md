# v12 純演算法 16 幀混合

預設採用隨時間遞減的相位保護。相位給出 8×8 網格中每個 2×2 Bayer 區塊的位置，
保持資料的 CFA 排列。同一相位重複出現時由較新的幀提供量測。

對每個已有量測的位置，該幀的 decoded RAW8 權重為 `1.00 - 0.02 × 幀齡`。本幀、
前 1 幀、前 15 幀依序為 1.00、0.98、0.70。剩餘比例由其他幀的最近色塊填補結果
按下節做 50/50 混合，計算時排除相位所屬幀。用整數百分點計算，最後向下取整。
未被任何一幀量測的位置沿用全窗口的 50/50 混合。

## 最近色塊填補

每幀輸入是 160×4 RAW8，視為 80×2 個 2×2 Bayer 色塊。依該幀相位將它們定位到
320×8 的目標色塊網格。每個目標色塊四個 byte 一起複製最近的來源色塊，保持 CFA 排列。
等距時取右方或下方的來源，超出範圍時使用邊界色塊。輸出為 640×16 RAW8。

## 50/50 混合

取同一區塊本幀到前 15 幀的最近色塊填補結果，按新到舊的順序混合。
計算某相位的剩餘比例時，從最新可用幀起算並跳過該相位所屬幀。

```text
mixed = nearest_bayer[t]
for age = 1 .. 15:
    mixed = floor((mixed + nearest_bayer[t-age]) / 2)
```

每次混合用 16 位元累加避免溢位，再向下取整回 RAW8。
各次混合都用上一步的結果。依這個順序，在忽略取整時，最後混入的 t−15 權重是 50%，
t−14 是 25%，本幀是 1/32,768。16 幀跨度為 0.5 秒（30 FPS）。

缺幀、換場與資料切分處重置歷史。數值評估使用完整的 16 幀窗口，影片在暖機期使用本幀
最近色塊填補。方法沒有權重、訓練或標籤輸入。Q=5 評估取 schema v4 所存的真實 JPEG XS
decoded，標籤只在輸出後讀取。紀錄見 [權重遞減實驗](../實驗紀錄-v12相位權重遞減Q5.md)、
[最近色塊實驗](../實驗紀錄-v12最近Bayer色塊Q5.md)、
[相位保護實驗](../實驗紀錄-v12相位保護Q5.md) 與 [原始固定混合實驗](../實驗紀錄-v12-16幀混合Q5.md)。

評估入口是 [evaluate_v12.py](../evaluate_v12.py)，使用 `--db`、`--scene-plan`、
`--out` 和選用的 `--video`。`--phase-decay-points 0` 可重跑相位量測權重為 1 的對照。
`--blend-mode fixed` 使用最近色塊填補後的全畫面 50/50 混合。

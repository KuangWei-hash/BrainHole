# v9 再簡化：單層 4→4，148 參數，Q=5

## 目的與改動

依使用者要求，將 v9 的兩層 `4→8→4` CNN（588 參數）再簡化為 **單個 3×3、4→4 卷積**（144 權重＋4 bias＝148 參數）。移除隱藏層及 ReLU；保持原 v9 的固定 RGGB 相位對齊 bilinear 放大、加回修正、RAW 交錯與最後 clamp [0,1]。

```text
Q=5 本幀本條 decoded RAW＋phase
    → RGGB 分平面／相位對齊 bilinear 放大
    → 四平面 [4,8,320]
    → 單層 Conv3×3 4→4
    → 加回放大四平面 → RAW 交錯 → clamp [0,1]
```

卷積本身是共享的仿射空間濾波，末端仍有 clamp；不宣稱整條流程完全線性。仍不使用 encoded、length、前幀、上一條、embedding 或時間融合。卷積零初始化，因此初始預測等於 bilinear。仍須實測學到的濾波有沒有改善。

單層設定保存 `architecture=v9, v9_layers=1, image_convolutions=1, hidden_channels=0`。CLI 訓練預設改為單層；原兩層權重未保存 v9_layers，載入時預設還原為兩層以保持相容。明確 `--v9-layers 2` 可重現原兩層架構；warm-start 禁止跨層數，舊權重與結果不覆寫。

## 資料與公平比較

Q=5 schema v4 資料與 decoded-q5-v4.npz 不變，levels=1/0、Br=4；資料庫 SHA-256 `11c05bdd430ba67fa84a986288c9e48786b92aded73fa38c51661acaac8975eb`。兩個模型都只用本幀本條 decoded＋phase。

- 訓練 frame 0…719，共 21,600 窗口；驗證 frame 720…899，共 **5,400 窗口**。
- 單層與原兩層均從頭完整五輪，Adam lr=0.001、batch=8、seed=42、FP32、RAW L1 loss；不截短步數，不載入舊模型權重。
- 此次兩種 v9 的資料、輸入、切分及輪數相同；架構初始化形狀不同，相同 seed 不代表相同初值，相同輪數亦不代表相同計算量。
- 比較使用兩個 v9 都完整涵蓋的 5,400 窗口；不與先前含 v7 的共同 5,370 窗口直接混比。
- 原兩層在完整 5,400 窗口的 MAE 為 16.646705／PSNR 20.014616 dB；bilinear 17.544584／19.708695 dB。本次重新載入兩層最佳權重，在同一次評估中比較。

## 完整比較結果

同一次評估使用 frame **720…899、5,400 窗口**，兩種 v9 均為各自最佳第 4 輪：

| 方法 | 參數 | RAW MAE | RAW PSNR |
| --- | ---: | ---: | ---: |
| nearest | 0 | 19.276165 | 18.490834 dB |
| bilinear | 0 | 17.544584 | 19.708695 dB |
| 原兩層 v9 | 588 | **16.646705** | **20.014616 dB** |
| 單層 v9 | **148** | 16.836493 | 19.949886 dB |

**單層仍通過數值初篩**：MAE 比 bilinear 降低 **4.04%**，PSNR 增加 **0.241 dB**，逐條同時勝過兩放大基準比例 **99.02%**。原兩層的逐條勝率為 92.56%，但整體 MAE／PSNR 仍較佳；勝率與平均誤差不能互相取代。

單層參數比原兩層少 **74.83%**，MAE 多約 0.1898；本次證明一層小型濾波也能帶來數值改善，未證明它是所有可能模型中最小、或最好的架構。未執行新影片、完整視覺或即時效能驗收。

影片誤差變化診斷為 bilinear 15.175699、兩層 13.919200、單層 14.247535；沒有光流對齊，不單獨判定閃爍。已檢視 frame 750 預覽，單層仍明顯模糊、有像素塊與水平條帶，不宣告完整視覺改善。

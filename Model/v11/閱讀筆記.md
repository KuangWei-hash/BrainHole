## 1. BasicVSR_PlusPlus（ckkelvinchan）— 對齊模組的主要來源

授權：Apache-2.0。commit `bbd417c6ac3b995148e98960f4b7458900774889`。

### 看過的檔案

- `mmedit/models/backbones/sr_backbones/basicvsr_pp.py`（17.2 KB）
- `mmedit/models/common/flow_warp.py`
- `configs/basicvsr_plusplus_reds4.py`

### 值得借用的結構

`BasicVSRPlusPlus.__init__` 的預設組態：

```python
mid_channels=64, num_blocks=7, max_residue_magnitude=10,
is_low_res_input=True, spynet_pretrained=None, cpu_cache_length=100
```

對齊模組 `SecondOrderDeformableAlignment(2*mid_channels, mid_channels, 3, padding=1,
deform_groups=16, max_residue_magnitude=max_residue_magnitude)`，流程在 `propagate()`：

```python
cond_n1 = flow_warp(feat_prop, flow_n1.permute(0, 2, 3, 1))
cond = torch.cat([cond_n1, feat_current, cond_n2], dim=1)
feat_prop = self.deform_align[module_name](feat_prop, cond, flow_n1, flow_n2)
```

**可借用的核心思想**：「光流當基準位移 + 網路學殘差修正」，且殘差被
`max_residue_magnitude` 夾住。這比讓網路從零學絕對位移穩定得多，是本專案
對齊模組的第一選擇。

### 不可直接搬用的部分

- **雙向 grid propagation**：`modules = ['backward_1', 'forward_1', 'backward_2', 'forward_2']`
  會讀未來影格，違反 [作法.MD](../作法.MD) 的因果性要求。只能取其單向版本。
- **RGB 三通道輸入**：`ResidualBlocksWithInputConv(3, mid_channels, 5)`。本專案輸入是
  160×4 Bayer，必須拆 CFA 平面處理。
- **SPyNet 光流**：在 160×4 的 Bayer 條帶上做光流不成立（見設計文件 §5.3）。

## 2. deep-burst-sr（DBSR，Goutam Bhat 等）— 最接近本專案的問題

授權：**CC BY-NC-SA 4.0（非商用）**。commit `16f158e0553b6702cc1693c43f733c2830973278`。
對應論文為 CVPR 2021「Deep Burst Super-Resolution」（arXiv 2101.10997）。

> 授權提醒：此 repo 為非商用授權。若本專案要商用，只能借用其**方法思想**並自行實作，
> 不可直接複製其程式碼。

### 看過的檔案

- `models/dbsr/merging.py`（`WeightedSum`）
- `models/dbsr/dbsrnet.py`、`models/dbsr/encoders.py`、`models/dbsr/decoders.py`
- `models/alignment/pwcnet.py`
- `models/loss/spatial_color_alignment.py`
- `dataset/burstsr_dataset.py`

### 值得借用的部分

**`WeightedSum`**（`models/dbsr/merging.py:21`）是「把 burst 各幀自適應融合成一份」的
可直接對應本專案的模組：

```python
base_feat_proj = all_feat_proj.mean(dim=1, keepdim=True)   # base = 平均
feat_diff_proj = all_feat_proj - base_feat_proj             # 與 base 的差
offsets_feat = self.offset_feat_extractor(offsets_all)     # 位移特徵
weights = self.weight_predictor(torch.cat([base_feat_proj, feat_diff_proj, offsets_feat], dim=1))
weights_norm = F.softmax(weights, dim=1)
fused_feat = (all_feat * weights_norm).sum(dim=1)
```

其中 `offsets_all % self.offset_modulo` 這一段特別關鍵：**只用子像素位置的餘數**
來描述每幀的取樣偏移。本專案的 phase 偏移是已知且精確的（不需估計），所以可以把
「偏移特徵」換成「phase 編碼」，省掉估測。

**`models/loss/spatial_color_alignment.py:23` 的 `match_colors`** 用高斯平滑後以最小平方法
估計兩幀之間的 3×3 顏色變換矩陣，並以 `err < 20` 產生有效遮罩。本專案是 Bayer，
對應物是「逐 CFA 平面的色偏／增益校正 + 有效遮罩」，用於把不同幀的量測對齊到同一色彩基準。

### 不可直接搬用的部分

- 輸入是 sRGB 影像；DBSR 的 PWC-Net 對齊假設整幅 RGB 影像，本專案的 16 列條帶不成立。
- `WeightedSum` 的 `use_base_frame` 用「平均」當 base，這在 Bayer 跨色時要小心（平均會跨色混合）。

## 3. FlashVSR（OpenImagingLab）— 對應 1.11 ms／區塊 的效能預算

授權：Apache-2.0。commit `0d403ee351905cb1d5eb802855cc4c1f0f4cf929`。論文：
「FlashVSR: Towards Real-Time Diffusion-Based Streaming Video Super-Resolution」（arXiv 2510.12747）。

### 值得借用的部分

- repo 以 `diffsynth` 為底（`diffsynth/models/cog_dit.py`、`cog_vae.py`、`flux_dit.py`），
  是**擴散式**即時 VSR 的完整實作，正好對應本專案 v10 已採用的條件式殘差擴散路線：
  同一套擴散骨幹可以從「單幀條件」擴到「多幀條件」。
- 稀疏注意力 + 輕量解碼器的取捨，對本專案的 640×16 條帶形狀有參考價值
  （條帶極扁，注意力成本低）。

### 不可直接搬用的部分

- 8× 上採樣、整幀 RGB、VAE latent 空間，與本專案的 RAW 像素域 + 4× 上採樣完全不同。
- 依賴大型預訓練模型權重（本機僅取得程式碼，未取得權重）。

## 4. RVRT（JingyunLiang）— 遞迴 + 引導式可變形注意力

授權：**CC BY-NC 4.0（非商用）**。commit `a5d406cd77c687774c5553bc57048e92b161829b`。
論文 arXiv 2206.02146。

### 值得借用的部分

「局部 N 幀並行 + 全域遞迴」的分層結構，正好對應本專案「每幀只處理自己、
但借用鄰幀特徵」的因果需求：可以取其遞迴骨架而不取其離線的全序列處理。

### 不可直接搬用的部分

- Transformer 骨幹相對於本專案的 1.11 ms 預算過重（v9 只有 2.95M 參數）。
- 授權為非商用。

## 5. TTVSR（researchmm）— 測試時訓練

授權：MIT。commit `b8edc01464b79f9b050f32d4ad9d1f24faf63cb3`。論文 arXiv 2204.04216。

- 用於對照「離線 + 逐測試影片最佳化」的極致結果。
- **不可用**：完全違反因果性（要看到整段影片才能最佳化），且延遲不可接受。
- 授權最寬鬆，若日後需要離線品質上限參考可優先考慮。

## 6. TecoGAN（thunil）— 時序一致性的生成式先例

授權：Apache-2.0。commit `bc747a4651c1e08bd0a73bed08c4cb9fac99b4d5`。
論文 arXiv 1811.09393（arXiv 上的標題為「Learning Temporal Coherence via
Self-Supervision for GAN-based Video Generation and Beyond」，即 TecoGAN 的擴充版）。

- 已在 [可以參考的方法.md](../可以參考的方法.md) 列為參考架構。
- 提供 FRVSR 訓練模式與時空判別器實作，是「生成 + 時序一致」的既有程式碼來源。
- 限制：RGB 輸出、GAN 訓練在 RAW 條帶上不直接適用；[驗收標準.md](../驗收標準.md) 也要求
  不能靠單一感知分數決勝。

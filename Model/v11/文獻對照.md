# v11 文獻對照：Temporal SR / Burst SR 與本專案的對應

本檔只記錄**實際取得並讀過**的文獻。查證狀態分三級：

- **已開頁確認**：本機有 PDF，標題經 arXiv API 回查或 CVF 官方檔名確認（見
  [refs/papers/論文清單.json](./refs/papers/論文清單.json)，25 篇全部 verified）。
- **搜尋摘要**：只讀到搜尋結果或摘要，**未取得全文**，僅作線索。
- **未取得**：嘗試過但失敗，記錄嘗試方式。

本專案特有的結構（相位逐幀輪替、16 相鋪滿 8×8 tile、Bayer 條帶只有 16 列）
在一般 VSR 文獻中**沒有對應物**，因此下列對照多數只能借用「方法部件」，
不能照搬整體設計。

## 5. 文獻沒有替本專案背書的部分

- 所有 VSR 文獻都在 **RGB、整幅影像** 上驗證；沒有人在 **160×4 Bayer 條帶**上做過
  時間對齊。本專案的對齊模組必須自行設計與驗證。
- 上述文獻的 PSNR 數字**不可**與本專案的 RAW MAE／PSNR 混比（不同集合、不同預算）。
- 「Temporal SR 有效」在本專案只有 §2 的量測支持（靜態區域累積誤差不隨 T 增長），
  **運動區域的處理方式仍待驗證**。

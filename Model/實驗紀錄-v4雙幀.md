# v4 雙幀：當前為主、前一幀為輔

## 正式輸入與輸出

時間窗口由 16 幀改為 **2 幀**，順序固定：

```text
索引 0：當前 t      [encoded_t,   decoded_RAW_t]     主畫面
索引 1：前一幀 t−1  [encoded_t−1, decoded_RAW_t−1]   輔助資訊
                              ↓
                   當前的 640 × 16 RAW8 RGGB
```

兩幀皆取相同 block_index；每份 decoded 都由自己的 encoded 實際解碼而來。
不能只提供歷史 decoded 而省略歷史 encoded，也不能在缺少 t−1 時跳去取 t−2。
encoded 張量 `[B,2,640]`，decoded 張量 `[B,2,1,4,160]`、float32、0…1，另有兩份 phase 與有效長度。
當前 decoded 的放大結果有直接輸出路徑；歷史資料經過特徵融合協助預測殘差。
固定衰減 0.2 的融合權重約為當前 0.5498、前一幀 0.4502；不是最終像素貢獻的固定比例。

`train.py` 預設 history 已改為 2。舊 1／16 幀 checkpoint 繼續依其設定載入，作為比較。
v4 主幹仍是 4 個殘差區塊、24 通道、52,452 個參數，沒有更改高解析度 RAW L1 學習目標。

## 完整訓練

從頭訓練 5 輪，Adam lr=0.001、batch size 8、seed 42、FP32、殘差幅度 0.5。
使用既有 Q=6 影片，來源訓練區段 frame 0…719、驗證區段 720…899，歷史不跨切分。

- 訓練有效當前幀 1…719，**21,570 個窗口**。
- 驗證有效當前幀 721…899，**5,370 個窗口**。
- 沒有 max-steps／val-steps 截短，最佳 checkpoint 依完整驗證 MAE 選出。

| 輪次 | 訓練 MAE | 完整驗證 MAE | 完整驗證 RAW PSNR |
| --- | ---: | ---: | ---: |
| 1 | 22.82 | 27.09 | 17.20 dB |
| 2 | 20.46 | 22.31 | 18.37 dB |
| 3 | 18.96 | 21.43 | 18.55 dB |
| 4 | 18.19 | 21.39 | 18.56 dB |
| 5 | 17.50 | **20.60** | **18.75 dB** |

最佳權重為第 5 輪。

## 單幀／雙幀／十六幀：相同窗口比較

三者共同有效範圍為 frame 735…899，共 **4,950 個窗口**。
兩幀版在這個集合的數字與上表完整 5,370 窗口不同，不能混用。

| 方法 | RAW MAE ↓ | RAW PSNR ↑ | 區塊 MAE 同時勝過兩種放大對照 |
| --- | ---: | ---: | ---: |
| 解碼＋nearest | 30.41 | 15.96 dB | — |
| 解碼＋bilinear | 28.76 | 16.65 dB | — |
| 單幀 v4 | 21.23 | 18.48 dB | 98.48% |
| **雙幀 v4（正式版本）** | **20.81** | **18.65 dB** | **97.43%** |
| 舊十六幀 v4 | 20.71 | 18.87 dB | 96.73% |

雙幀較單幀平均 MAE 降約 2.0%，3,190／4,950 區塊（64.44%）的 MAE 改善。
相對十六幀，雙幀平均 MAE 高約 0.10（約 0.5%），PSNR 低約 0.22 dB；
2,488／4,950 區塊（50.26%）的 MAE 優於十六幀，代表局部結果互有勝負。
三個模型均通過本組資料的數值初篩。這組資料上雙幀平均品質接近十六幀，但不能宣稱完全等價。

單幀版原先訓練 3 輪，雙幀與十六幀各 5 輪，訓練窗口數也不同。
此表是同樣本上的候選結果比較，不是完全同預算的架構消融；仍只有單影片驗證，沒有獨立新影片測試。

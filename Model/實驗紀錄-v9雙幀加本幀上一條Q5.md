# v9 雙幀＋本幀上一條，四層 128 通道，Q=5

> 後續決策：使用者決定不再使用上一條，回到 v9「本幀本條＋前幀本條」四層 relu128 雙幀版。本次實驗已結束且不採用；下列原始結果、權重與失敗紀錄保留，未改寫實測數值。

## 目的與輸入

依使用者要求，以 v9 雙幀四層 relu128 為基礎，再加入當前幀上一條的實際 decoded RAW。輸入順序為 `(t,b)`、`(t−1,b)`、`(t,b−1)`，目標仍為 `(t,b)` 的 640×16 RAW8。沒有上一幀上一條、下方條帶、未來幀、encoded 學習分支或模型生成的上一條。

各份 160×4 decoded RAW 依自己的 phase 做 bilinear 上採樣，拆成四個 CFA 平面，按通道串接，再附加上一條有效性遮罩，共 13 通道。CNN 為 `13→128→128→128→4`，3×3 卷積、前三層 ReLU，殘差加回當前本條 bilinear，clamp [0,1]。共 314,884 參數；雙幀無上一條為 309,124，增加 5,760（約 1.86%）。這是通道上下文融合，沒有將條帶沿高度拼接成連續影像，也沒有運動補償。

每幀 block 0 的上一條缺席：decoded 填零、phase=-1、length=0、tokens 全為 padding，模型將其 CFA 特徵乘零，並輸入有效性 0；其餘上一條有效性為 1。明確的邊界表示不是實際解碼資料，也不借用別幀／末條；缺失時間歷史仍跳過，有 block>0 卻缺上一條時也跳過，不偽造。

此功能使用獨立 `--v9-upper-strip`，不復活已停用的 v7 `previous_block` 權重。使用者本次明確要求鄰條，這是新的 v9 消融；舊版結果與原契約保持原紀錄。v9 預設仍單幀，上一條功能預設關閉。

## 資料、預算與比較

資料：`training-data-preparation/拆好的訓練資料/big-buck-bunny-30s-q5-shared-v4-raw8.sqlite`；實際解碼快取：`runs/decoded-q5-v4.npz`。與前次雙幀實驗相同：train split 0…719，有效目標 1…719、21,570 條；validation split 720…899，有效目標 721…899、5,370 條。時間歷史不跨切分，上一條僅來自當前幀同一 split。

從頭完整五輪，seed=42、FP32、Adam lr=0.001、batch=8、RAW L1，依最低驗證 MAE 選 best.pt。雙幀參考沿用前次同資料、同切分、同五輪的最佳第 5 輪權重，在相同窗口重新評估，不宣稱重訓。主對照仍為同筆當前本條輸入的官方 FSR 1 EASU 2x＋2x＋RCAS 0，另報無 RCAS、bilinear。上一條是本次新增資訊，FSR 不額外使用它。

## 狀態

實作已完成，47 項測試通過，包含第三份 decoded 的正確 `(t,b−1)` 配對、相位回繞、時間切分與缺失條帶篩選、第一條的缺席遮罩、上一條梯度與輸出依賴、遮罩為零時不受該槽內容影響，以及 checkpoint 重建。新功能同時接入 train、predict、evaluate 與 evaluate_fsr。完整五輪訓練及官方 FSR／雙幀參考評估均已完成，最佳第 5 輪。所有執行保留 run_logged，逐輪保存 update_active_record，不覆寫前次結果。

### 第一條與其餘條帶

| 分組 | 樣本數 | 新模型 RAW MAE | 雙幀 RAW MAE | 新模型勝率 |
| --- | ---: | ---: | ---: | ---: |
| 每幀第一條 block 0，上一條缺席 | 179 | 15.023479 | 12.895791 | 0% |
| block 1…29，有本幀上一條 | 5,191 | 14.271125 | 14.215094 | 51.61% |

第一條明顯退步，是具體失敗模式；其餘條帶也沒有平均收益，不能把全部退步只歸咎於第一條。遮罩能明確表示缺席，但不保證網路會自動維持舊模型的邊界品質。訓練預算、融合位置、有效性遮罩學習或新增資訊的用法都有可能影響結果，尚未經消融確定原因。

最大退化區塊皆為第一條：frame 792 block 0，雙幀 12.862163、新模型 15.957937（+3.095775）；frame 779 block 0（+3.010481）；frame 807 block 0（+2.855894）。前十筆保留在 report 的 `largest_regressions_vs_reference`，不能改寫或刪除。

已查看 frame 750 的七欄比較 PNG，標籤／佈局正常，仍可見水平條帶、模糊與紋理流失。完整 179 幀、30 FPS 的離線影片已輸出，尚未完整觀看，不宣告視覺或時間一致性驗收通過。

**本次結論：保留實驗開關與產物，但不建議以這個權重替換原雙幀版本。** 這否定的是本次「通道串接＋遮罩、五輪」的改善主張，不能據此斷言上一條資訊永遠無用。

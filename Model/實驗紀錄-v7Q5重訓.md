# v7 使用 Q=5 資料完整重訓

## 目的與設定

依使用者要求，使用目前 Q=5 資料從頭重訓原 v7：五個兩層 `24→48→24` 殘差區塊、114,828 參數。本幀本條＋前幀本條各有 encoded 與實際 decoded RAW，沒有上一條；輸出為本幀本條 640×16 RAW8 RGGB。

資料庫 `training-data-preparation/拆好的訓練資料/big-buck-bunny-30s-q5-shared-v4-raw8.sqlite`，schema v4、Q=5、levels=1/0、Br=4，SHA-256 `11c05bdd430ba67fa84a986288c9e48786b92aded73fa38c51661acaac8975eb`。快取 `runs/decoded-q5-v4.npz` 取自 Go 實際解碼結果，綁定資料庫與 header 指紋；全 27,000 筆已與 Rust 解碼逐 byte 核對一致。

- Big Buck Bunny 30 秒、900 幀；高解析度標籤、來源幀／時間／相位與原 Q=4 相同。
- 訓練來源 frame 0…719，有效當前 1…719，共 21,570 窗口。
- 驗證來源 frame 720…899，有效當前 721…899，共 5,370 窗口；歷史不跨切分。
- 從頭完整五輪，Adam lr=0.001、batch=8、seed=42、FP32、decay=0.2、residual_scale=0.5，不截短步數。不載入 Q=4 或 Q=6 權重。
- 同影片保留集、單一 seed；同輪數不代表不同架構有相同計算量。不同 Q 的分數不混作同輸入條件的架構比較。

| 方法 | RAW MAE | RAW PSNR |
| --- | ---: | ---: |

模型同時勝過兩種放大基準，**數值初篩通過**。相較 bilinear，MAE 降低 **13.85%**、PSNR 增加 **1.085 dB**；逐條同時勝過兩種基準比例 **99.96%**。Q=4 與 Q=6 分數僅留作不同編碼條件的歷史參考，不能把本次差異全部歸因於架構或直接宣告跨 Q 的最佳方案。

影片誤差變化診斷由 bilinear 的 15.184004 降至 v7 的 10.929151；沒有光流對齊，不單獨當成閃爍驗收。已檢視 frame 750 的預覽，仍有模糊、水平條帶及與標籤不同的局部明暗，尚未通過完整視覺驗收。新影片泛化及 batch=1 完整串流效能也未驗收。

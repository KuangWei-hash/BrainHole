# v13：以 v12 為底的 RAW 條帶修復

2026-11-22 建立。狀態：設計階段，尚未實作模型、建立 v13 訓練資料快取或啟動訓練；本文的架構、損失與預算都是待驗證方案。

使用者已將 **v12 現有視覺品質定為堪用的最低合格線**。v13 要保留其可見結構，再減少條紋、壓縮誤差、顆粒和歷史錯位，使成果更接近原始目標條。MAE 追蹤內容失真，不取代人眼驗收。

```text
本幀與前 15 幀的同條 decoded RAW8＋phase
                    ↓
         固定 v12 相位遞減 0.02 底圖
                    ↓
      底圖＋相位量測值＋量測年齡／有效遮罩
                    ↓
       一次前向的 CFA 四平面殘差 CNN
                    ↓
           底圖＋修正量 → RAW8 條
```

第一版維持因果、逐條獨立，輸出 640×16 RAW。不讀鄰條、未來幀、原始影片或目標標籤作推論輸入，不依賴先前生成圖。不同方法各自輸出 640×480、30 fps 影片，不產生 `comparison.mp4`。

## 為什麼另開 v13

v10 已試過 bilinear 底圖與凍結 B 的高頻殘差生成，不能把「改用殘差」當作全新突破。這次改動是以 v12 已可用的多相位量測成果為起點，先做可追溯的修復，不先要求隨機生成缺失材質。

同區間 736–750 幀、450 條，v10 第 40 輪 gamma 0.5 的 RAW MAE 12.6744，v12 為 13.5680，但對齊畫面的 v12 材質與輪廓明顯更清楚。這是必須保留的反例：[既有比較](../實驗紀錄-v10-v12同區間成果比較20261122.md)。

v12 的完整窗口基準為 736–899 幀、4,920 條，RAW MAE 14.2552、RGB MAE 12.0070、固定座標相鄰幀殘差變動 3.7456。它們是既有觀測，不是 v13 成績，也不能與其他窗口直接混比：[v12 紀錄](../實驗紀錄-v12相位權重遞減Q5.md)。

## 下一個具體工作

先完成不讀 target 的 v12 底圖與輔助量測張量產生器，逐值確認與現有 v12 相同；再實作零初始化的小型殘差 CNN，驗證 alpha=0 和初始輸出等於底圖。通過輸入／切分／紀錄檢查後，才執行小場景可行性實驗。實作與訓練尚未發生，不提供假裝可執行的 v13 訓練指令。

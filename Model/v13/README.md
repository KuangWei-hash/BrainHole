# v13：以 v12 為底的 RAW 條帶修復

2026-11-22。已完成 S0 至 S2。R2 第 17 輪、alpha 0.5 在 BBB Q=5 同片保留審核降低 RAW MAE 13.6%。使用者看完有效窗口影片，判定合格，與 v12 的差距沒有顯著拉開。跨片泛化和即時效能待驗。[S0 紀錄](../實驗紀錄-v13-S0.md) · [S1 紀錄](../實驗紀錄-v13-S1.md) · [S2 紀錄與影片](../實驗紀錄-v13-S2.md)

2026-11-23。以開發窗選定時間趨勢與原生校正 64 通道的等權候選後凍結，回到已看過的 795–899 幀重測，RAW MAE 為 10.5100。字面橫紋減少，局部材質和淡出仍與原始目標有距離。新組目視、跨片與即時效能待驗。[凍結、結果與影片](../實驗紀錄-v13-逐幀融合.md#最終凍結與歷史重測)

使用者已將 **v12 現有視覺品質定為堪用的最低合格線**。v13 的目標是在固定 v12 底圖上，把材質、輪廓與動態重建得更接近原始目標 RAW，並在原解析度影片中看出明顯改善。減少條紋、壓縮誤差、顆粒和歷史錯位是手段，MAE 用來追蹤內容失真。

```text
本幀與前 15 幀的同條 decoded RAW8＋phase
                    ↓
         固定 v12 相位遞減 0.02 底圖
                    ↓
      底圖＋相位量測值＋量測年齡／有效遮罩
                    ↓
       一次前向的 CFA 四平面殘差 CNN
                    ↓
           底圖＋修正量 → RAW8 條
```

第一版維持因果、逐條獨立，輸出 640×16 RAW。不讀鄰條、未來幀、原始影片或目標標籤作推論輸入，不依賴先前生成圖。不同方法各自輸出 640×480、30 fps 影片，不產生 `comparison.mp4`。

## 為什麼另開 v13

v10 已試過 bilinear 底圖與凍結 B 的高頻殘差生成，不能把「改用殘差」當作全新突破。這次改動是以 v12 已可用的多相位量測成果為起點，先做可追溯的修復，不先要求隨機生成缺失材質。

同區間 736–750 幀、450 條，v10 第 40 輪 gamma 0.5 的 RAW MAE 12.6744，v12 為 13.5680，但對齊畫面的 v12 材質與輪廓明顯更清楚。這是必須保留的反例：[既有比較](../實驗紀錄-v10-v12同區間成果比較20261122.md)。

v12 的完整窗口基準為 736–899 幀、4,920 條，RAW MAE 14.2552、RGB MAE 12.0070、固定座標相鄰幀殘差變動 3.7456。它們是既有觀測，不是 v13 成績，也不能與其他窗口直接混比：[v12 紀錄](../實驗紀錄-v12相位權重遞減Q5.md)。

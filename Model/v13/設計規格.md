# v13 設計規格

版本：草案 1，2026-11-22。所有未有實測的模型選擇均為設計假設。專案根目錄為 `W:\BrainHole`，歷史文件的 `Z:\BrainHole` 不是新的預設工作路徑。

## 1. 問題與假設

目標為重建當前幀本條的原始 RAW，而非產生看似銳利的隨機紋理。主假設 H1：凍結 v12 已重建的結構，學習 `target − v12` 的修正，比 v10 兩幀擴散更容易保住可見細節。H2：量測年齡能幫助區分較新的可靠內容與較舊的潛在錯位。兩者尚未驗證。

v12 的 16 相位可覆蓋完整網格，僅代表幾何取樣位置齊全；不同時間的物體可能已移動。量測年齡不是經校準的置信度，相位對齊也不是運動對齊。單條高 16 列，內容移出本條後，任何本條模型都不能直接讀回該區域。

第一版不使用擴散、GAN、預訓練 RGB 生成器或光流網路。這是為了先分辨修復是否有用，不是宣稱它們永遠沒有價值。相關研究與適用範圍見[文獻對照](文獻對照.md)。

## 2. 固定底圖

底圖 `B` 必須重用 [v12](../v12/__init__.py) 的 `nearest_bayer_bytes` 和 `phase_protected_blend`，`decay_points=2`，保留 RAW8 整數運算、向下取整、最近色塊等距處理及排除 owner 的混合順序。

v12 的剩餘比例混合採新到舊逐步 50/50；忽略取整時，最後加入的舊幀在該混合鏈權重較大，不是一般的「最新幀權重最高」平均。首版忠實保留，不順便重設演算法。

## 3. 輸入、時間與狀態契約

對輸出 `(video, header, frame=t, block=b)`：

- 接收同一條 t、t−1…t−15 的真實 JPEG XS decoded，各為 `[1,4,160] uint8`，phase 為 0…15。DB 的 phase_id 是 1…16，邊界只轉換一次。
- 模型前處理順序固定 newest-first。窗口枚舉可沿用 v11 的 oldest-first，但必須顯式轉換，不能讓方向由呼叫方猜測。
- 檢查連續幀、同影片、header／CFA／尺寸一致；缺幀、切場、換片、header 改變或資料切分均重置。
- 首版只對完整 16 幀窗口做 AI 修復。暖機沿用 v12 的本幀最近 Bayer 色塊，標記 `fallback=warmup`；不要將暖機成果冒稱 AI 結果。
- 已有場景清單使用來源影片離線偵測，只供實驗重現。正式串流需由上游提供 cut/reset 訊號或另做 decoded-only 切場偵測；不能宣稱現有清單就是可部署切場器。
- 推論不讀 target 或原片。標籤限資料訓練與輸出後評估；同一 loader 同時持有標籤並不算已證明無洩漏，須另測 target-free 輸入路徑。

前處理產生下列量，全部只依 decoded、phase、窗口狀態計算：

| 符號 | RAW 空間 | 定義 |
| --- | --- | --- |
| B | `[N,1,16,640]` | 固定 v12 底圖，從 uint8 正規化至 0…1 |
| M | `[N,1,16,640]` | 每個已量測位置的最近 owner decoded 值；缺值填 0 |
| A | `[N,1,16,640]` | owner 的 age/15，未量測填 1；age 0 是本幀 |
| V | `[N,1,16,640]` | 量測有效遮罩，0／1 |

M 是帶有壓縮誤差的觀測，不能當成乾淨標籤。完整正常輪替時 V 全 1，但保留該通道作明確契約；首版不宣稱學會處理未訓練的缺失相位。

對 B、M 作 `pixel_unshuffle(2)` 得四個 CFA 平面 `[N,4,8,320]`，通道序以既有 RGGB 與 PyTorch 的 row-major 順序為準。A、V 在同一 2×2 Bayer 色塊內相同，各取左上代表成 `[N,1,8,320]`，先驗證四位置一致。不要直接在未拆 Bayer 的 RAW 上以同色假設作梯度或插值。

R1 的模型輸入 `concat(pack(B), pack(M), A_cell, V_cell)` 共 **10 通道**。第一版不輸入 block 編號、絕對幀號或影片 ID，避免把場景位置當作材質線索。M 沒有「對齊運動」，它只描述精確取樣網格上的歷史觀測。

## 4. 首版網路與輸出

採同尺寸小型殘差 CNN，R0 和 R1 僅輸入通道不同：

```text
輸入 C=4 (R0) 或 C=10 (R1)，8×320
Conv3×3 C→32 + SiLU
4 個 residual block，每個 Conv3×3 32→32 + SiLU + Conv3×3 32→32
Conv3×3 32→4，weight/bias 零初始化
delta = unpack(輸出)
raw_float = B + alpha × delta
raw8 = round(clamp(raw_float, 0, 1) × 255)
```

各 block 為 `x + 0.1*f(x)`；卷積 stride=1、dilation=1、replicate padding。不降採樣；高度只有 8 個 CFA 格，不先套大型 U-Net。首版不用 BatchNorm 或跨樣本正規化；不同 batch 組成不應改變推論結果。

alpha 固定預設 1；0 僅作 bypass 與回退控制，0.5 只列預登錄的修正強度診斷。不能按驗證 target 逐條挑 alpha。初始模型須逐值等於 B，alpha=0 須直接走底圖 byte 路徑。零初始化輸出層即可，不再將另一個乘法 gate 同時初始化為零，以免阻斷學習。

訓練使用未裁切 `raw_float` 的損失，避免硬 clamp 的零梯度掩蓋越界；評估統一裁切／量化，另報裁切前 MAE、越界比例、delta RMS／最大值。量化前與 RAW8 分數分開，主要成片評估使用 RAW8。

R1 按上述層數估算 **78,052 參數、每條約 0.199 GMAC**（只計卷積乘加、不含前處理、SiLU、搬移及顯色）。900 條／秒約需 179 GMAC／秒的卷積工作量，這不是延遲實測，也不是「小模型就一定即時」。FP32 權重約 0.30 MiB；顯存還有 activation、optimizer、底圖與歷史狀態。先實作後重算參數、測整體效能。

## 5. 學習目標

R0／R1 初始主損失為全頻 RAW L1：`mean(abs(B+delta−Y))`，不強迫殘差高通。條紋、明暗與輪廓都有可能需要修正。資料正規化 0…1，不沿用 v10 擴散的 residual_scale。

R2 僅在 R1 仍抹掉細節時加入同色平面梯度項：

`L = L1_RAW + 0.1 × (mean|Dx(pack(P))−Dx(pack(Y))| + mean|Dy(pack(P))−Dy(pack(Y))|)`

Dx／Dy 是各 CFA 平面的一階差分，兩方向各自求平均；係數 0.1 是預登錄假設，不是研究證明的最優值。高頻能量不是驗收指標，增加梯度也可能加重噪聲。

第一版不加跨幀平滑損失。直接懲罰 `P_t−P_{t−1}` 會把真實運動抹掉；若後續需要時序項，應比較相鄰幀的預測誤差或作可信的運動對齊，另列 ablation。其額外窗口可能需 17 幀資料，不能偷偷擴張首版輸入。

不把當前 decoded 值硬鎖回輸出：它有 JPEG XS 壓縮誤差。量測一致性先作診斷，再決定是否加軟約束；也不把所有歷史量測當作當前幀真值。

## 6. 能力邊界與後續分支

若相同底圖在不同真值下產生相似輸入，單靠後修復仍可能平滑或猜錯。M、A 可補回混合時的部分資訊，但無法恢復已丟失的整段歷史。若失敗集中在舊量測／運動區，下一版再比較「保留 v12 直接路徑，額外編碼各幀 decoded 的自適應融合」，而不是盲目加寬網路。

若連小樣本過擬合都不能降低真實修復誤差，先查 CFA、phase、窗口方向和底圖一致性；若小樣本可修、保留區不行，優先查資料覆蓋與模型選擇偏差。只有在可信修復已超過 v12 後，才把生成模型列為另一條實驗。

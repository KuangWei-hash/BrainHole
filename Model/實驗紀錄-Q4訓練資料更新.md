# Q=4 訓練資料更新

> 後續狀態：使用者已要求 v7 以 Q=4 完整重訓，五輪與完整 5,370 窗口評估均已完成，結果見 [v7 Q=4 重訓紀錄](./實驗紀錄-v7Q4重訓.md)。下文「尚未完整重訓」為當次資料更新完成時的歷史狀態，短流程原始數值不改寫。

## 目的與變更

依使用者要求將正式資料由 Q=6 改為 Q=4，沿用 Big Buck Bunny 30 秒來源影片、640×480、30 FPS、16 相 RGGB、每幀 30 條、每條 640×16 RAW8 標籤與 160×4 輸入。levels=1/0、Br=4，其餘取樣與編碼設定不變。實際從影片重新產生資料，沒有只改 metadata 或使用高解析度標籤冒充 decoded。

新資料由原生 Go encoder 編碼、Go decoder 實際解碼，另存 schema v4；既有 Q=6／Q=8 資料與權重保留。模型現在接受 v3／v4；v4 的解碼快取和單條推理可直接讀取庫內 decoded，v3 仍保持原有外部快取／解碼方式。資料／快取以 SHA-256 綁定，舊 Q=6 模型的 header 也不能直接當成 Q=4 模型使用。

## 完整資料驗證

來源 `原始影片/big-buck-bunny-1080p-30sec.mp4`，SHA-256 `07b756a4c7b481829776645c153167ca14c9df802ddbea7dffda3d817aa5261a`。

- 900 幀、27,000 筆、全部 16 相；每幀完整 30 條，錯誤 0，PRAGMA quick_check=ok、status=complete。
- 與 Q=6 的 27,000 筆高解析度 RAW8 標籤、來源幀序號、時間與相位逐筆完全相同；27,000 筆 payload 都已變更。
- payload 44…413 bytes、平均 **248.5154 bytes**，完整碼流最大 **515 bytes**，未超過 640-byte 上限。
- 只傳 payload 的封裝主體（長度＋幀序號）約 **1,804,670.93 bps**，不含共用設定及網路封包。對照 Q=6 約 702.4 kbps；降低量化的資料成本明顯增加。
- 解碼後全 128 為 **17／27,000＝0.063%**；Q=6 為 439／27,000＝1.63%。這是精確全 128 的比例，不是整體資訊量或模型品質分數。
- 將全部 27,000 筆完整碼流交給既有 Rust decoder，與 Go 保存的 decoded **全部逐 byte 相同**。兩端 17,280,000 bytes 解碼資料的 SHA-256 同為 `fafa2b4e4271da70781ab95ebbe9e6ffeb2579ee66965d91cf8cb7295bddf442`。

## 解碼缺陷與失敗紀錄

第一次原生 Go 產生在 output frame 31、block 25、phase 16 中斷：slice parser 用搜尋 FF20／FF11 找分界，將有效 entropy 裡的 FF20 誤認為新 slice，報 marker segment 超出 buffer。原不完整檔 `big-buck-bunny-30s-q4-shared-v4-raw8.sqlite` 及失敗 prepare-q4-report 全部保留，不能用於訓練。

修正為按 precinct header 與 Lprc 長度定位 slice 邊界，不掃描 entropy 中的 marker 字樣。加入實際失敗 RAW 樣本及 Rust 解碼預期值，測試內嵌 FF20／FF11、不完整 precinct 與無效長度。修正後重新以新檔名產生全部資料，未續寫或冒用失敗產物。

Go 全部套件測試通過；Python 模型／紀錄共 20 項通過，新增 v4 快取、v4 直接解碼欄位讀取、錯誤長度拒絕、不同資料庫快取拒絕。Python 第一次新增測試因 fixture 缺少 shared_header.singleton 欄位失敗，修正 fixture 後重跑通過；兩次檢查紀錄均保留。

Q=4 真實資料另外通過 v7 CUDA 短流程：2 個訓練 batch、2 個驗證 batch，各 16 窗口，僅跑 1 輪（partial_steps）。可用集合仍為訓練 21,570、驗證 5,370 窗口。此檢查不代表完整訓練或品質驗收，未以其誤差與原五輪 Q=6 模型比較。尚未以 Q=4 完整重訓 v7 或 v8。

## 重現

輸出檔不可重用，重跑請另取新的 database 與 report 名稱：

```powershell
.\Model\.venv\Scripts\python.exe Model/prepare_dataset.py --source training-data-preparation/原始影片/big-buck-bunny-1080p-30sec.mp4 --reference training-data-preparation/拆好的訓練資料/big-buck-bunny-30s-q6-shared-v3-raw8.sqlite --encoder-config training-data-preparation/encoder.native.q4.json --database training-data-preparation/拆好的訓練資料/big-buck-bunny-30s-q4-shared-v4-raw8-repeat.sqlite --out Model/runs/prepare-q4-repeat-report.json
```

所有比較目前限相同一部來源影片。資料更新及解碼一致性通過不代表新影片泛化、視覺或即時效能驗收通過。

# v7 使用 Q=4 資料完整重訓

## 目的與設定

依使用者要求，原 v7 五個兩層 `24→48→24` 殘差區塊、114,828 參數，使用目前 Q=4 資料從頭訓練。保持本幀本條＋前幀本條，兩幀都有 encoded 與實際 decoded RAW；沒有上一條。輸出仍為本幀本條的 640×16 RAW8 RGGB。

資料為 `training-data-preparation/拆好的訓練資料/big-buck-bunny-30s-q4-shared-v4-raw8-fixed.sqlite`，schema v4、Q=4、levels=1/0、Br=4；SHA-256 `033f850f92e65b87eea6d00f28e6c46af9f18d07b44f25182c90fe01e0ca970d`。decoded-q4-v4.npz 取自庫內原生 Go 解碼結果，已核對整份資料與 Rust 解碼逐 byte 相同，並綁定資料庫雜湊。

- 來源 Big Buck Bunny 30 秒、900 幀、27,000 條；高解析度目標／時間／相位與先前 Q=6 相同。
- 訓練來源 frame 0…719，有效當前 1…719，共 21,570 窗口。
- 驗證來源 frame 720…899，有效當前 721…899，共 5,370 窗口，歷史不跨切分。
- 從頭完整 5 輪，Adam、lr=0.001、batch=8、seed=42、FP32、decay=0.2、residual_scale=0.5。未載入 Q=6 權重，也未延續先前兩步 smoke 權重。
- 只限同影片保留集與單一 seed，不代表新影片泛化。先前 Q=6 成績屬不同編碼輸入條件，不作為 Q=4 放大基準。

正式五輪訓練已完成。每輪曲線與 best.pt／last.pt 已保存，所有命令由 run_logged 紀錄。最佳驗證 MAE 在第 1 輪，後續輪數沒有改善。

這次曲線很早停滯；不能因 Q=4 的絕對誤差低於先前 Q=6 模型就宣稱神經網路改善，輸入的壓縮品質與資料率也同時改變。完整評估已使用相同 5,370 窗口的 **Q=4 正常解碼＋nearest／bilinear** 作驗收。未額外加輪數或自行調整超參數。

| 方法 | RAW MAE | RAW PSNR |
| --- | ---: | ---: |
| Q=4 nearest | 16.116439 | 19.083681 dB |
| Q=4 bilinear | **14.497267** | 20.471392 dB |
| Q=4 v7 最佳第 1 輪 | 14.504695 | **20.471827 dB** |

模型 MAE 比 bilinear 高約 0.007428（0.051%），PSNR 僅高約 0.000435 dB，品質幾乎相同，**數值初篩未通過**。逐條同時勝過兩放大基準比例為 41.53%。本次只證明訓練完成，尚未證明 v7 在 Q=4 上提供超越正常解碼放大的價值；曲線停滯的具體原因尚未進一步診斷，不以推測當成結論。

影片誤差變化診斷：bilinear 13.108783、v7 13.100382，只有微小差異；無光流對齊，不能獨立作為閃爍驗收。已檢視 frame 750 的對照 PNG，模型與 bilinear 外觀幾乎相同，都仍有模糊、像素塊與條帶，不能宣告視覺改善。完整視覺、新影片泛化與串流效能仍未驗收。

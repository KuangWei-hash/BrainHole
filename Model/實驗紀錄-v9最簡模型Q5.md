# v9 最簡模型：Q=5、單幀 decoded、兩層 CNN

> 後續新增了 148 參數單層及兩層維持 4 通道的比較。本檔保留原兩層 588 參數實驗與數值；目前程式重現本檔架構須明確加 `--v9-layers 2 --v9-variant relu8`，舊 checkpoint 仍可直接還原。

## 目的與架構

依使用者要求重新設計最單純的 v9，保留小型非線性影像修正能力，移除先前複雜分支。僅使用本幀本條的實際 Q=5 decoded RAW 與取樣 phase，不使用 encoded bytes、length 特徵、前幀、上一條、byte encoder、phase embedding、時間融合、殘差區塊堆疊、Tanh 或可調殘差縮放。

```text
160×4 decoded RAW + phase
    → 固定 RGGB 分平面／相位對齊 bilinear 放大
    → 四平面 [4,8,320]
    → Conv3×3 4→8 → ReLU → Conv3×3 8→4
    → 加回原放大四平面 → RGGB 交錯 → clamp [0,1]
    → 本幀本條 640×16 RAW
```

只有兩個可學習卷積，共 **588 參數**（296＋292），v7 為 114,828。末層零初始化，因此初始結果恰為同一份 decoded 的 bilinear 放大；訓練後仍須驗收。固定放大正確保留 RGGB 與 16 相座標，未直接混色插值 Bayer。

共用 CLI 的 forward 仍接受 tokens／lengths 以保持既有資料、推理與評估工具相容，但 v9 不讀取這兩項特徵；input_contract 明確保存 `decoded_raw_only_v1`。history 固定 1，config 保存 byte_encoder=false、temporal_fusion=false、hidden_channels=8、image_convolutions=2。v1～v8 舊模型仍以原架構載入。

## 資料與預算

Q=5 schema v4 資料 `big-buck-bunny-30s-q5-shared-v4-raw8.sqlite`，levels=1/0、Br=4；資料庫 SHA-256 `11c05bdd430ba67fa84a986288c9e48786b92aded73fa38c51661acaac8975eb`。快取 decoded-q5-v4.npz 來自庫內原生 Go decoded，已與 Rust 全 27,000 筆逐 byte 核對一致。

- 訓練 frame 0…719，共 **21,600** 單幀窗口；驗證 frame 720…899，共 **5,400** 窗口。
- v7 的雙幀需跳過每個切分首幀，原訓練 21,570、驗證 5,370。v9 模型本身不需要前幀，不為湊數丟棄有效資料。
- 從頭完整五輪，Adam lr=0.001、batch=8、seed=42、FP32、RAW L1 loss。未 warm-start、未截短步數。
- 單獨完整評估使用 v9 全 5,400 窗口；與 v7 的共同評估限定 frame **721…899，5,370** 窗口。不能把兩個集合的分數直接混比。
- 本次同時簡化輸入與架構，且訓練窗口數略異，不能當成僅調整參數量的控制實驗；相同五輪不代表相同計算量。只限同影片保留集及單一 seed。

## 完整驗證與共同窗口比較

完整單幀保留集為 frame **720…899、5,400 窗口**：v9 MAE **16.646705**／PSNR **20.014616 dB**，bilinear 為 **17.544584／19.708695 dB**，nearest 為 **19.276165／18.490834 dB**。數值初篩通過，MAE 相較 bilinear 降低 5.12%，逐條同時勝過兩放大基準比例為 92.56%。

以下另取共同 frame **721…899、5,370 窗口**，與既有 Q=5 v7 比較：

| 方法 | 參數 | RAW MAE | RAW PSNR |
| --- | ---: | ---: | ---: |
| nearest | 0 | 19.283259 | 18.483525 dB |
| bilinear | 0 | 17.552326 | 19.701981 dB |
| v7 雙幀 encoded＋decoded | 114,828 | **15.121942** | **20.787027 dB** |
| v9 單幀 decoded | **588** | 16.654964 | 20.007607 dB |

共同窗口的 v9 亦通過數值初篩，MAE 比 bilinear 降低 **5.11%**，逐條同時勝過兩放大基準比例 **92.51%**。v9 參數比 v7 少 **99.49%**，品質仍落後 v7；本次保留它作簡單基準，不宣稱取代 v7 品質。輸入與訓練窗口也不同，不能將差異全部歸因於參數量。

共同影片的誤差變化診斷：bilinear 15.184004、v7 10.929151、v9 13.927007；未做光流對齊，不單獨當成閃爍驗收。已檢視 frame 750 的對照 PNG，v9 仍有明顯像素塊、模糊與水平條帶，不宣告完整視覺改善。新影片泛化與串流效能未驗收，未以訓練時間或參數量宣稱即時。

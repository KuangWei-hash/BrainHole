# v13 S0 與 S0-fit

2026-11-22。目的為確認 v13 前處理可逐 byte 重現 v12，並以極小樣本檢查殘差模型有學習訊號。正式同片畫質由 S1 與後續審核評估。

## 資料與設定

BBB Q=5 schema v4。S1 訓練來源 691–719 幀，有效 706–719 幀、420 條。S1 開發來源 721–750 幀，有效 736–750 幀、450 條。兩區各自重置 16 幀歷史。快取只含由 decoded 產生的 B/M/A/V 與窗口 metadata，標籤由訓練及評估入口另讀。

S0-fit 從 S1 訓練 keys 等距抽取固定 32 條，用 R1、RAW L1、seed 42、FP32、AdamW 1e−4、batch 16、microbatch 4、clip norm 1，進行 200 次更新。紀錄中的分數來自該 32 條訓練樣本。

## 觀測

- 16 種相位方向的底圖皆逐 byte 與既有 v12 一致。SQLite 封鎖 target 欄位後仍能讀取推論輸入。CFA pack 往返、量測位置和 age、暖機、重複相位、零初始化與 alpha=0 檢查通過，R1 實測 78,052 個參數。[S0 自動紀錄](experiments/records/checks--v13-S0-20261122-213702-930--run-7fe9088c9337.json)
- 擬合診斷中，量化 RAW8 MAE 由 v12 的 13.5029 降到第 200 次更新的 12.1172。曲線持續下降，進入 S1 的固定預算對照。[S0-fit 曲線](experiments/records/training--v13-S0-fit-20261122-214125-695--run-d0b6cffeb86c.json)
- 開發基準 v12 的 RAW/RGB MAE 為 13.5680/11.1569，固定座標時序差分 3.5340，同色 CFA 條界差分 15.3359；固定 unsharp 分別為 16.2712/12.6485、4.1628、18.9468。兩組各有 14 個相鄰幀 pair，固定銳化在這些量測均退步。影片已完整解碼驗證為 640×480、30 fps，共 30 幀；有效版 15 幀。ROI 取自開發畫面並在 S1 訓練結果前凍結。[評估紀錄](experiments/records/evaluation--v13-S1-baseline-20261122-214047-719--run-5a4e6cf23eb0.json) · [ROI](v13/roi-bbb-q5.json)
- v13、v12 與記錄器的 15 項回歸通過，涵蓋缺幀、header 與資料切分重置、部分 microbatch 權重及 ties-to-even 量化。離線推論的暖機例使用 5 幀，`alpha=0` 例使用 16 幀並各自輸出 10,240 bytes RAW。[回歸紀錄](experiments/records/checks--v13-S0-regression-20261122-214554-316--run-daf5ba3aebe2.json) · [暖機 metadata](runs/v13-S0-predict-20261122-214244-901/warmup.json) · [alpha 0 metadata](runs/v13-S0-predict-20261122-214244-901/alpha0.json)

## 失敗與恢復

首次 S0-fit 在第 1 輪寫總表時遇到既有索引器硬性讀取 `psnr_raw`。同時期的基準評估也在啟動索引時失敗，函式尚未進入。修正索引時的一次重試因縮排錯誤在 Python 匯入時停止；修正後，併發啟動又重現 SMB 的快照寫入衝突。改成每次先保存獨立紀錄，暫存快照經雜湊驗證後才置入共用路徑，訓練曲線持續寫入 JSON，總表在實驗結束刷新。新的基準評估與擬合診斷均完成。[首次擬合](experiments/records/training--v13-S0-fit-20261122-213811-316--run-02fd723b110e.json) · [首次基準評估](experiments/records/evaluation--v13-S1-baseline-20261122-213925-243--run-9c809efad75c.json)

S1-R0 首跑完成 8 輪後，在第 9 輪更新 best checkpoint 時遇到 SMB 暫時拒絕置換。保留部分曲線與產物，checkpoint 改用唯一暫存檔與有限重試，再從頭執行同一配置。[S1-R0 中斷紀錄](experiments/records/training--v13-S1-R0-20261122-214218-958--run-dd1d7babdc74.json)

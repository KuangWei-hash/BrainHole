# v7 增加上一條上下文

> 後續狀態：使用者要求拆掉上一條，正式程式已恢復原 v7 本條雙幀版，採用 `runs/hybrid-v7-history2-expand2/best.pt`。下列為當次實驗原始結果，不因停用而改寫；重現上一條版請使用該次紀錄的來源程式快照。

## 目的與改動

依使用者要求放棄 v8 主方案，回到 v7 五個兩層擴張收縮殘差區塊（24→48→24）。增加本幀及前幀各自上一條，輸入順序固定為 `(t,b)、(t−1,b)、(t,b−1)、(t−1,b−1)`；四組均包含實際 encoded 與 decoded。輸出與標籤仍只有 `(t,b)` 的 640×16 RAW8 RGGB。

不是將四組當成四幀融合。在每條內分別按原時間權重融合，再將上條特徵接在本條上方，CNN 跨交界運算後裁取下半部。本條 decoded 放大仍有直接路徑。參數仍為 114,828，計算空間由一條增加至兩條；尚不宣稱即時。

頂部 b=0 的上方使用專用 padding token 256、length 0、decoded 0，在融合前遮罩，不查詢負索引。其餘上條缺失、前幀缺失或跨切分時略過窗口。保留舊 checkpoint 與舊版兩組輸入載入方式。新上下文不自動套用舊權重，從頭訓練以公平比較。

## 資料與設定

沿用 Big Buck Bunny 30 秒 Q=6 schema v3、真實 JPEG XS 解碼快取 decoded-q6.npz。訓練 frame 0…719，有效當前幀 1…719、21,570 窗口；驗證 frame 720…899，有效當前幀 721…899、5,370 窗口，包含每幀第一條。

正式預算為 5 輪、Adam lr=0.001、batch=8、seed=42、FP32、時間衰減 0.2、殘差幅度 0.5，從頭訓練。對照舊 v7 同五輪／同 5,370 窗口 MAE 19.865、PSNR 18.986 dB。單一 seed 與同影片保留集不建立新影片泛化結論。

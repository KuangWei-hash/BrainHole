# v10 decoded＋bilinear 雙路殘差擴散：實作與首輪 Q=5 訓練

## 實作狀態

v10第一版已實作，可訓練、載入checkpoint、執行不讀原圖標籤的單條推理，並輸出完整畫面比較及獨立生成影片。主線不載入v9權重，不使用上一條／鄰條或未來影格。生成品質尚未通過驗收。

| 程式 | 功能 |
| --- | --- |
| [v10/model.py](./v10/model.py) | decoded低解析特徵分支、bilinear分支、相位及時間條件去噪器 |
| [v10/diffusion.py](./v10/diffusion.py) | cosine噪聲排程、DDIM eta0、逐鍵seed、生成強度與低頻濾波 |
| [v10/data.py](./v10/data.py) | 雙幀本條配對、train-only殘差尺度、固定分層選模鍵值、無標籤推理入口 |
| [train_v10.py](./train_v10.py) | 擴散、無噪聲Charbonnier修復、單次噪聲L1三種訓練模式，梯度累積與逐輪紀錄 |
| [predict_v10.py](./predict_v10.py) | 單條RAW／RGB輸出，不讀raw_bayer_target欄位 |
| [evaluate_v10.py](./evaluate_v10.py) | gamma／seed、bilinear、銳化、匹配高頻噪聲、v9、正式FSR及可選非生成控制比較 |
| [test_v10.py](./test_v10.py) | 相位、分支梯度、反解、seed、batch分拆與無標籤讀取驗證 |

來源快照已擴充包含v10子目錄的Python與設計文件，保留相對路徑，不漏掉sampler或生成器。所有入口經run_logged，訓練逐輪update_active_record，舊實驗不覆寫。

## 輸入、架構與演算法

外部輸入為decoded `[B,2,1,4,160]`、同份decoded依自身phase產生的bilinear RAW `[B,2,1,16,640]`、phase `[B,2]`。slot0是本幀本條，slot1為緊接前幀本條。直接呼叫模型時可用validate_inputs(check_pair=True)核對來源一致；CLI使用共用bilinear實作，不以標籤產生輸入。

decoded每幀先拆成4×2×80，在低解析網格用共用Conv 4→16→16提特徵，再依相位座標對齊到8×320，兩幀共32通道。bilinear四平面每幀4通道，共8通道，phase embedding共16通道，加上帶噪殘差4通道，融合輸入60通道。主體寬度48，4個時間FiLM殘差區塊、每個兩層3×3，水平dilation 1／2／4／8，GroupNorm(8)、SiLU、replicate padding。實際共 **280,340參數**，包含條件分支與時間embedding。

訓練目標是`(P(target)-P(current_bilinear))/s`，對帶噪殘差預測epsilon。主實驗只用epsilon MSE；可選低頻護欄已提供，但本次權重為0，不能把未執行消融當作結果。兩種非生成控制也已實作，但尚未完成相同20輪預算的訓練。

排程為cosine s=0.008、1,000時間步、beta上限0.999，DDIM預設32步、eta=0。每步預測乾淨殘差時依底圖與尺度投影到物理RAW [0,1]界限，再由截取後x0重新計算epsilon，維持下一步一致性。此處只限制數值範圍，不能保證內容正確。

輸出為bilinear＋gamma×尺度×生成殘差。gamma=0精確等於本幀bilinear。條件特徵在一次採樣中只計算一次，步間重用。seed由video/DB指紋、seed值、frame、block穩定雜湊，提供per_frame與fixed_screen政策，不依batch順序決定。

## 正式訓練與目前觀測

正式run為 [v10-diffusion-q5-20epochs](./runs/v10-diffusion-q5-20epochs/config.json)。資料為BBB Q=5 schema v4、實際decoded快取，資料庫SHA256 `11c05bdd430ba67fa84a986288c9e48786b92aded73fa38c51661acaac8975eb`。

- train split 0…719，有效目標1…719、**21,570條**；validation split 720…899，有效目標721…899、**5,370條**，不跨切分。
- 每輪完整訓練21,570條、1,349個optimizer steps。首輪設定共20輪、seed42、AdamW lr=1e-4、weight_decay=1e-4、FP32、有效batch16、microbatch4／實際樣本加權累積、gradient clip1.0。
- 尺度只在完整train擬合，四CFA標準差為0.079234145、0.077459128、0.078137293、0.078475401；完整統計保存於config。
- 每輪用固定256條、32步、seed0、gamma1的生成RAW MAE選暫定best.pt；完整5,370條尚未評估。此代理選模不代表感知最佳，保留5／10／20輪候選供後續視覺檢查。gamma 0／0.25／0.5／0.75／1均保存數值。

第一輪實測：訓練epsilon objective **0.308351**，訓練143.44秒；256條生成驗證7.94秒，gamma1 RAW MAE **77.305240**／PSNR **8.457421 dB**。同一256條的gamma0 bilinear為 **17.271231**／**20.087501 dB**。初期生成明顯不合格，不能只用去噪loss下降宣稱有效，也不能把256條的bilinear分數和5,370條的17.552326混比。

**目前20輪訓練仍在執行。** 完整曲線與當下狀態以 [metrics.jsonl](./runs/v10-diffusion-q5-20epochs/metrics.jsonl) 及experiments/records中的running／completed狀態為準；本段只記已觀測的首輪，不預造最終分數或最佳輪。

追加觀測：第2輪訓練objective 0.209633、固定256條gamma1生成MAE 79.655432／PSNR 8.289343 dB，仍嚴重失真，且比首輪差。這再次表明去噪訓練loss下降不等於採樣品質改善；目前沒有品質通過的v10權重。

## 評估範圍與尚未完成事項

評估程式支援同窗口逐條RAW／RGB指標、最差10%、phase分組、已知取樣誤差、低／高頻誤差、同CFA跨條誤差跳變、負面條塊，以及不同gamma／seed。高通噪聲控制的能量由固定64個train鍵值的生成殘差校準，不看validation原圖；銳化固定為四平面Gaussian5 sigma1、unsharp alpha0.5。

正式FSR可重用既有官方atlas，但必須核對DB指紋與frame/block鍵值；report保存來源report雜湊。v9只在評估作獨立參考，不參與訓練條件。比較影片與單獨generated.mp4使用同一主輸出gamma1。

尚未完成：正式20輪結果、同預算S1控制、完整5,370條生成評估、固定ROI與人工盲比、LPIPS、時序微調、新影片及即時效能。首版獨立片源評估尚需先保存／重用train的噪聲控制校準，不能在新片源上重估控制來冒充train-only。現階段不能宣告生成／視覺／泛化／部署通過。

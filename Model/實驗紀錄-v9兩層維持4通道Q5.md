# v9 再加一層，維持 4 通道：4→4→4，Q=5

## 目的與結構

依使用者要求，在目前單層 4→4 v9 下方再接一層，所有卷積均維持 4 通道。沿用單層版沒有 ReLU 的設定，實作為：

```text
本幀本條 Q=5 decoded RAW＋phase
    → 固定 RGGB 分平面／相位對齊 bilinear 放大
    → 四平面 [4,8,320]
    → Conv3×3 4→4 → Conv3×3 4→4
    → 加回原放大四平面 → RAW 交錯 → clamp [0,1]
```

每層 144 權重＋4 bias，共 **296 參數**，FP32 純參數 **1,184 bytes**，不含輸入／中間張量或 runtime。兩個卷積中間沒有 activation，內部局部感受野可覆蓋 5×5；末端仍有 clamp，不能將整條流程稱為完全線性。只使用 decoded＋phase，不使用 encoded、length、前幀、上一條、embedding 或時間融合。

第一層維持一般隨機初始化，最後一層零初始化，使初始整體輸出恰為 bilinear，又能在末層開始學習後將梯度傳回第一層。沒有從單層權重續訓，以同樣從頭訓練方式比較。

config 保存 `architecture=v9, v9_layers=2, v9_variant=plain4, hidden_channels=4, activation=none`。原單層 148 參數與原 4→8→4＋ReLU 的 588 參數版均保留相容；舊 checkpoint 無 v9_variant 時按原 relu8 載入。CLI 預設為兩層 plain4，重現原 588 參數版需指定 `--v9-variant relu8`。

## 資料與預算

Q=5 schema v4，levels=1/0、Br=4，資料庫 `big-buck-bunny-30s-q5-shared-v4-raw8.sqlite`，SHA-256 `11c05bdd430ba67fa84a986288c9e48786b92aded73fa38c51661acaac8975eb`。decoded-q5-v4.npz 來自真實 Go 解碼，與資料庫指紋核對；來源碼流全部與 Rust 解碼結果逐 byte 相同。

- Big Buck Bunny 30 秒；單幀本條輸入，輸出本條 640×16 RAW8 RGGB。
- 訓練 frame 0…719，共 21,600 窗口；驗證 frame 720…899，共 **5,400 窗口**。
- 與原兩種 v9 採相同資料／切分／窗口／五輪預算：Adam lr=0.001、batch=8、seed=42、FP32、RAW L1，從頭訓練、不截短步數。相同 seed 不表示不同架構初值相同，相同輪數也不等於相同計算量。
- 原單層完整 5,400 窗口 MAE 16.836493／PSNR 19.949886 dB，原 relu8 兩層 16.646705／20.014616 dB；本次將在同次評估重新載入最佳權重比較。不能混用含 v7 的 5,370 共同窗口分數。

## 完整比較結果

同一次評估使用 frame **720…899、5,400 窗口**，三個 v9 都載入各自五輪中的最佳權重。

| 方法 | 參數 | RAW MAE | RAW PSNR |
| --- | ---: | ---: | ---: |
| nearest | 0 | 19.276165 | 18.490834 dB |
| bilinear | 0 | 17.544584 | 19.708695 dB |
| 單層 4→4 | 148 | 16.836493 | 19.949886 dB |
| **本次兩層 4→4→4，無 ReLU** | **296** | **16.806699** | **19.995103 dB** |
| 原兩層 4→8→4＋ReLU | 588 | 16.646705 | 20.014616 dB |

本次兩層 4 通道 **數值初篩通過**，相較 bilinear 的 MAE 降低 **4.21%**、PSNR 增加約 0.286 dB，逐條同時勝過兩種放大基準比例 **99.78%**。相較單層，MAE 僅降低 **0.029794**、PSNR 增加 **0.045216 dB**，增益很小；只有單一 seed 與同影片保留集，未建立統計穩定性或新影片泛化結論。此結果不證明「多一層必然較好」。

影片誤差變化診斷：bilinear 15.175699、單層 14.247535、本次 4 通道兩層 13.959415、原 8 通道兩層 13.919200。未做光流對齊，不單獨當成閃爍驗收。已檢視 frame 750 的對照 PNG，本次版本仍有明顯模糊、像素塊與條帶，不宣告通過完整視覺驗收；即時效能與新影片也尚未驗收。

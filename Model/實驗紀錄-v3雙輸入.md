# v3：encoded＋decoded RAW → 高解析度 RAW

本頁為淺層 v3 的歷史基準；目前主幹已改為 4 個殘差區塊，結果見 [v4 實驗紀錄](./實驗紀錄-v4四殘差區塊.md)。

## 學習目標的變更

encoded 與同一份碼流實際解碼出的低解析度 RAW，都是訓練與推理的正式輸入。
模型不再需要學會近似 JPEG XS 解碼，而是以已有畫面為基礎，學習修復與超解析。
標籤仍為 SQLite v3 的當前區塊 640 × 16 RAW8 RGGB。

```text
encoded [B,T,640] → 小型 byte encoder ────────────┐
                                                ├→ CNN 殘差修正 → 高解析度 RAW
decoded [B,T,1,4,160] → phase 對齊放大／時間融合 ─┘         ↑
                           當前放大結果的直接路徑 ─────────┘
```

encoded 對應的有效長度與 phase 仍作輔助資訊。decoded 正規化為 float32 0…1。
decoded 必須來自實際解碼，不得用原始高解析度標籤降採樣替代。
接收端可以自行解碼，因此新增模型輸入不等於新增網路傳輸負載。

殘差頭以零初始化，未訓練時等於當前 decoded 的 phase-aware bilinear 放大。
訓練 loss 只有高解析度 RAW L1；`--auxiliary-weight` 參數只對舊 v2 生效。
v3 有 15,996 個參數，預設殘差幅度 0.5。舊 v1／v2 權重不能直接載入 v3。

## 完整單幀實跑

GTX 1650 4 GB、PyTorch 2.7.1 CUDA 12.6，FP32、Adam lr=0.001、batch size 8、seed 42，完整 3 輪。
沿用 Q=6 同影片前 720 幀訓練、後 180 幀驗證，每輪 21,600 訓練區塊、5,400 驗證區塊。

| 輪次 | 訓練 MAE | 驗證 MAE | 驗證 RAW PSNR |
| --- | ---: | ---: | ---: |
| 1 | 22.32 | 22.22 | 18.27 dB |
| 2 | 20.08 | 22.58 | 18.22 dB |
| 3 | 19.44 | **22.14** | 18.25 dB |

按驗證 MAE 選擇第 3 輪權重，不是按最高 PSNR 選擇。

## 同一組 5,400 區塊的對照

| 方法 | RAW MAE ↓ | RAW PSNR ↑ |
| --- | ---: | ---: |
| 實際解碼＋nearest 放大 | 30.42 | 16.00 dB |
| 實際解碼＋bilinear 放大 | 28.76 | 16.68 dB |
| 舊純 bytes 最佳微調模型 | 30.09 | 14.79 dB |
| **新雙輸入 v3** | **22.14** | **18.25 dB** |

新模型在約 98.04% 區塊上的 MAE 同時低於兩種放大對照；平均 MAE 相較 bilinear 降低約 23.0%。
因此**通過本組資料的數值初篩**，不是宣告所有畫面或每個區塊都更好。
舊模型與新模型輸入條件不同，表格呈現整個方案的改變，不能把改善全歸因於架構或 encoded 分支。
encoded 分支的額外效益仍須與 decoded-only CNN 做消融比較；目前只確認其有接入模型且可接收梯度。

frame 750 的完整 RGB 對照中，新模型較能保留樹幹與洞口等輪廓，但仍有明顯條帶及細節不足。
尚未進行新影片、連續影片時間一致性或目標設備串流效能驗收；解碼時間也須納入端到端效能。

## 推理與測試

- 正式呼叫：`model(tokens, phases, lengths, decoded_raw)`；省略 decoded 會報錯。
- CLI 預設由實際 payload 即時重組碼流並解碼；可用同筆離線解碼快取作等價輸入。
- frame 750、block 7 的即時解碼與快取推理，輸出 **10,240-byte RAW 逐 byte 相同**。
- 六項 Python 測試通過，包含新模型的初始化基準、decoded 輸入依賴、兩分支梯度、1／16 幀形狀及既有窗口／CFA 檢查。
- 16 幀版已用真實資料完成短訓練與驗證的流程檢查，尚未完整訓練；本頁品質數據全部來自單幀版。

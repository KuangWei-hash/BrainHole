# v10 固定 B 草地材質實驗

## 問題與計畫

目標是同一部 BBB Q=5 影片在低解析資料缺失的位置補出看得出方向的草葉、葉片與材質。先分辨 B 能否承接清楚材質，以及舊擴散 C 是否已具備可用的高頻。

1. 凍結 B 第 17 輪及 C 第 12 輪。用幀 721–750 的 900 條資料並排比較 B、B 加 C 高頻、B 加等能量噪聲與 B 加原片高頻。最後一項只提供診斷上限，使用標籤。
2. 若原片高頻有用而舊 C 仍像顆粒，固定 B 並重新訓練同一 48 通道 v-prediction 去噪骨架。目標為同色 CFA 平面上 `高通(標籤 − B)`，高通沿用 5×5 Gaussian 的互補分量。模型仍吃原始 decoded 和相位對齊 bilinear，生成時把殘差疊到 B。
3. 先做同場景的小範圍可行性試驗。訓練使用幀 706–719，雙幀有效目標 707–719 共 390 條；驗證使用幀 720–750，雙幀有效目標 721–750 共 900 條。同一資料庫與 header，B 的舊訓練也未包含驗證時間區間。60 輪共 1,500 次更新，FP32、batch 16／microbatch 4、學習率 0.0001、seed 42，採樣保持 DDIM 32 步。固定 128 條做逐輪選模，另保留第 20、60 輪權重。
4. 用完整 30 幀比較 B、新模型與 B 加等能量噪聲，主 seed 0，seed 1 交叉驗證。先看草地、樹根、樹葉的已固定區域，再看幀間與條界。MAE 用於追蹤內容偏移。生成能否增加合理且連貫的材質由影片判讀。

## 凍結權重診斷

同段 900 條 RAW MAE 為 B 12.20、B 加 C 高頻 13.05、B 加等能量噪聲 12.92、B 加原片高頻 8.30。預覽中，原片高頻能在 B 上顯出草葉方向與葉簇，舊 C 高頻主要增加細斑。決定按步驟 2 啟動場景實驗。[診斷報告](runs/v10-b-detail-probe-20261122/report.json) · [比較影片](runs/v10-b-detail-probe-20261122/comparison.mp4)
